  DropHeads

Плагин для Minecraft, который добавляет выпадение голов мобов и игроков.

## Возможности

- Выпадение голов с мобов и игроков, убитых игроком.
- Головы разных разновидностей мобов, в том числе редкие трофеи.
- Настройка шансов выпадения. Зачарование «Добыча» повышает шанс выпадения голов мобов.
- Сохранение заданных в конфигурации названий голов после размещения и разрушения.

## Версия и требования

| Версия плагина | Целевой сервер | Java |
| --- | --- | --- |
| 1.2.11 | Paper для Minecraft 1.21.7 | 21 |

## Установка

1. Установите JDK 21 и Maven, затем выполните `mvn clean package` в папке проекта.
2. Скопируйте файл `target/DropHeads-1.2.11.jar` в папку `plugins` вашего сервера.
3. Перезапустите сервер. При первом запуске плагин создаст файл `plugins/DropHeads/config.yml`.

## Настройка

В файле `plugins/DropHeads/config.yml` можно изменить шансы выпадения, множитель зачарования «Добыча», текстуры и названия голов, а также сообщения.

Шансы задаются долями единицы: `0.05` означает **5%**. После изменения настроек перезапустите сервер.

По умолчанию названия голов и сообщения написаны на русском.

## Команда

```text
/gethead <head_tag>
```

Выдаёт голову моба, заданную в конфигурации. Команда доступна только операторам сервера. Вводите её в игре.

Тег — это имя параметра текстуры без окончания `_head_texture`. Например, для `pig_head_texture` используйте:

```text
/gethead pig
```
