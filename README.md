  DropHeads

Плагин для Minecraft: Java Edition 1.21.7, добавляющий выпадение голов с мобов и игроков при их убийстве игроком.

## Основные функции

- Головы мобов и игроков выпадают с заданным шансом при их убийстве игроком.
- Головы мобов отражают их разновидности: например, цвет овцы, породу кошки или профессию жителя.
- Головы игроков отображают скины убитых игроков.
- Зачарование «Добыча» повышает шанс выпадения голов, но только с мобов.
- Выпадение головы сопровождается сообщением на экране и звуковым сигналом.
- Шансы выпадения, текстуры и названия голов, а также сообщения настраиваются в конфигурации.

| Версия плагина | Целевой сервер | Java |

## Установка

1. Установите JDK 21 и Maven, затем выполните `mvn clean package` в папке проекта.
2. Скопируйте файл `target/DropHeads-1.2.11.jar` в папку `plugins` вашего сервера.
3. Перезапустите сервер. При первом запуске плагин создаст файл `plugins/DropHeads/config.yml`.

## Настройка

В файле `plugins/DropHeads/config.yml` можно изменить шансы выпадения, множитель зачарования «Добыча», текстуры и названия голов, а также сообщения.

Шансы задаются долями единицы: `0.05` означает **5%**. После изменения настроек перезапустите сервер.

При разрушении размещённой головы выпавший предмет получает соответствующее название из конфигурации. Это позволяет обновить названия уже полученных голов после изменения настроек и перезапуска сервера.

По умолчанию названия голов и тексты сообщений написаны на русском.

## Команда

```text
/gethead <head_tag>
```

Выдаёт голову моба, заданную в конфигурации.<br>
Команда доступна только операторам сервера. Вводите её в игре.

Тег — это имя параметра текстуры в конфигурации без окончания `_head_texture`.<br>
Например, для головы белой овцы (`white_sheep_head_texture`) используйте:

```text
/gethead white_sheep
```
